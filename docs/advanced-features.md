# 免费版高级功能与 WeHarbor 接入

入口为侧栏“高级功能”或 /advanced，聊天消息的编辑菜单会携带账户、会话和消息 ID 打开工作台，输入框的“准备发送”会带入原文与目标。全部功能已解锁，不再弹出高级版拦截弹窗；工作台按“可用”“已实现，待连接”“尚未实现”展示并可筛选。原有 WxCDN 配置与使用方式保留。

## 实现范围

当前本地 WeHarbor 源码提供 33 个 MCP 工具，使清单中的 **48 / 79 项具备执行路径**；仍发布 12 个工具的旧实例只有 31 项。需要同时部署匹配的 WeHarbor 与分析源码才能启用新能力。这个数字表示代码与接口能力，不表示已在真实微信账户完成验收。界面依据实例实际发布的工具启用功能；桌面布局不符合操作条件时会明确失败。

| 功能 | 实现与限制 |
| --- | --- |
| 8 项聊天编辑 | 文本、消息 XML 源码、时间、字段、还原、发送者映射、私聊双方互换、删除系统消息。修改分析用解密副本，支持预览修订检查、事务、编辑日志及冲突检查还原；不回写微信客户端。 |
| 17 项消息补录 | 写入现有会话消息表，支持还原。媒体、支付和复杂卡片必须提供原消息 XML，媒体资源须已存在。不会上传资源，也不会发生真实收付款。 |
| AI 助手与 MCP | /ai 使用官方 DeepSeek Harness；分析 MCP 提供 19 个工具，覆盖数据读取、能力发现、Action 准备/提交/取消/回执、任务草稿/控制、标签读取、朋友圈刷新、分析副本编辑。Skill 通过 MCP resource 和 WeHarbor 内置技能说明工作流。 |
| 接收消息、联系人变化记录 | 查询现有解密消息；完整联系人快照按小时或手动保存，比较新增、资料变化和不在当前列表中的记录，首次建立基线。只比较本地列表，不推断对方删除或拉黑了你。 |
| 发送文本 | 使用 WeHarbor /actions/prepare 和 /actions/{id}/commit。需要精确账户与 username、对应前台聊天和空草稿；最终状态依据 WeHarbor 回执。支持其定时发送接口。 |
| 文件、图片、视频发送 | 浏览器先经同源接口上传至 WeHarbor 的私有目录，限制 100 MiB；上传不会发送。准备时记录内容摘要，提交前检查文件、账户、会话和草稿，经过桌面文件选择器发送。只有匹配新自发消息的资源摘要才记为 sent；压缩或转码导致无法核对时记为 uncertain，不自动重发。 |
| 标记已读、免打扰 | 提交后才按精确身份导航聊天；免打扰使用明确布尔参数，读取控件状态并核对结果。 |
| 联系人备注、群名、我的群昵称、群公告 | 使用可访问性控件定位字段、保存并重新打开核对。当前只支持明确字段与保存按钮的布局，其他版本布局会拒绝执行；仍待真实账户验收。 |
| 群发 | 文字、图片、视频、文件表单及上传，支持显式打开每个目标聊天并标记已读。持久化草稿、明确启动、分步执行、暂停、继续和取消；每步使用稳定幂等键，按实例实际工具能力启用步骤。 |
| 联系人标签 | 读取完整标签列表，创建、改名、删除标签及设置联系人标签集合。必须使用精确名称、匹配的账号和入口聊天；列表不完整、名称重复或已有用户标签草稿时拒绝执行。准备后标签发生变化会取消；写入后重新打开读回核对。空数组清除该联系人标签；删除标签影响所有使用者，不删除联系人。 |
| 自动迎新 | 启动时记录完整通讯录基线，只处理之后新增好友，可限制明确收件人。示例先按精确身份打开聊天并标记已读，再执行备注、标签与欢迎语；各步骤有独立幂等回执，出错暂停，不自动重发。标签须先存在，示例内容须由用户填写并启动。 |
| 朋友圈刷新、连续同步 | 通过精确账户的原生朋友圈刷新控件刷新，再同步本地快照，按至少 30 秒间隔增量保存 HTML/JSON 与可获取的图片、视频。每个任务使用稳定私有目录，保留增量基线，重启可继续，缺失媒体可重试。任务记录保存位置、进度、增量统计和警告。需要可访问的原生刷新按钮；真实客户端布局仍待验收。 |
| 其余 31 项 | 表单、能力检查和 MCP 调用通道已接入，**微信执行驱动尚未实现**。包括其他发送及聊天操作、二维码、朋友圈互动/发布、其他群管理及联系人操作、在线找人、微信内容搜索和红包详情。界面显示“尚未实现”，不会返回模拟成功。 |

自动迎新依赖同步后的完整通讯录，不推断好友申请是否通过；两次同步之间出现又消失的联系人无法捕获。朋友圈连续同步替代旧“跟圈”入口；旧互动任务禁止启动/恢复，已有活动任务会暂停。新任务不执行点赞、评论、转发或自动回复。保存范围仅限账户当前可见且已同步的内容；无法恢复已删除、不可见或未下载的资源，导出警告会保留在任务记录中。

## WeHarbor 连接

在“连接设置”填写 WeHarbor 地址及 Workspace Bearer 令牌，或在分析服务配置：

~~~bash
WEHARBOR_URL=http://127.0.0.1:8766
WEHARBOR_TOKEN_FILE=/config/.config/weharbor/workspace.token
~~~

同容器可直连 Workspace 的 8766 端口。远程部署填写实际 WeHarbor 根地址，客户端自动使用 /workspace/；也可填写以 /workspace 结尾的地址。支持 WEHARBOR_API_TOKEN，优先于设置中保存的令牌。不要把令牌放进 URL。

配置、回执、任务、编辑日志和独立 MCP 令牌保存在 WECHAT_TOOL_DATA_DIR/advanced/，目录权限 0700，数据库及令牌权限 0600。前端读取设置不会获得令牌明文。保留此目录才能在重启后保留执行记录。

WeHarbor 检查前台账户、会话和草稿。准备请求保留 120 秒；提交中断会标记 uncertain，不会自动重发，需要人工核对原 WeHarbor 操作记录。修改连接配置后，旧准备记录不能转发到新服务，旧任务会暂停。

前后端分开部署时，在分析服务配置 WECHAT_TOOL_ADVANCED_ORIGINS 为允许写操作的前端完整 Origin，逗号分隔。默认接受同源写入；MCP 使用独立 Bearer 鉴权。

## DeepSeek Harness

在连接设置中配置 Harness 页面地址。WeHarbor 内默认 /assistant/，由其官方 Harness 服务提供。独立运行分析项目时，需填写实际 Harness 地址或部署同源代理。模型凭据与对话由 Harness 自己管理，分析项目不模拟模型回答。

WeHarbor 的 Harness 启动配置同时加载微信 MCP 和全部 19 个分析工具；更新匹配镜像后自动发现。现有 weharbor-api Skill 已补充分析 Action、任务与朋友圈保存用法，分析 MCP 也通过 resources/read 暴露 wechat-analysis://skill。独立部署可使用 docs/harness-analysis-mcp.yml，它是官方 @deepseek-ai/dsh-mcp-client 插件的 stdio 配置补丁，可通过 Harness 的 --patch 参数加载。应与已有 WeHarbor MCP 配置合并或一同加载，保留原有微信工具。启动前调整补丁中的 Python 路径、脚本路径、分析服务地址和令牌文件路径。

stdio 转接脚本为 scripts/advanced_mcp_stdio.py，可用以下环境变量覆盖配置：

| 变量 | 用途 |
| --- | --- |
| WECHAT_ANALYSIS_MCP_URL | 默认 http://127.0.0.1:10392/api/advanced/mcp |
| WECHAT_ANALYSIS_MCP_TOKEN_FILE | 分析服务生成的 advanced/mcp.token 的绝对路径 |
| WECHAT_ANALYSIS_MCP_TOKEN | 可选直接令牌，优先于文件 |

分析 MCP 与网页复用同一套 Action/任务服务和持久化回执。微信操作最终由 WeHarbor 驱动执行；Harness 负责模型与对话，分析项目不直连另一套模型。创建任务不会自动启动，prepare 不会发送；用户已授权的精确操作可以继续执行，不必重复确认同一授权。

## 扩展缺失驱动

只有 WeHarbor 的 tools/list 实际发布的工具才能启用在线操作。默认工具名为功能代码加 wechat_ 前缀并把连字符替换为下划线，例如 wechat_send_image。不同名称可在连接设置的工具绑定中映射；参数必须符合实际发布的 inputSchema。

绑定不会实现驱动。仍需在可访问且已登录的微信桌面实现、验证操作及结果回执，才能完成剩余 31 项。本地联系人查找工具 wechat_contact_lookup 只查询已有数据库，不代表在线找人。不要猜测未公开的微信偏移，或把本地数据库修改当作在线微信操作。
